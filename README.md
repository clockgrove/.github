# Clockgrove organization metadata

This public repository contains the shared GitHub organization profile and, when useful, organization-wide community health files.

The organization profile is rendered from [`profile/README.md`](profile/README.md).

Canonical project documentation lives with each project rather than here:

- `clockgrove/clockgrove` — persistent artificial-life world/runtime platform.
- `clockgrove/factory` — project-agnostic Director/Keeper software factory.
- `clockgrove/skills` — reusable procedural guidance for agents.
